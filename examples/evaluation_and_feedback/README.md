# 06 · 评测与反馈

评测模块五的策略，归档部署 Episode，诊断并回流失败样本，通过同条件专家恢复验证策略因素，重新训练后执行独立对照。

真机 Episode 必须同时提供 `source=real` 和不可变部署报告；仿真数据不会被标记为真机证据。物理参数辨识复用 `bounded_inverse_dynamics`，并要求两组独立、重力补偿的单关节真实采集。

在 PhysReal-X Conda 环境中运行 [demo.ipynb](demo.ipynb)。补充采集改变机械臂初始姿态，只使用成功专家示范训练；独立验收数据与父模型训练数据隔离。门控比较任务成功率和成功执行质量，默认至少 20 次评测；Demo 的 3 次评测仅展示流程。

输出：示范采集分布图、评测面板、失败/恢复/更新策略同步动画、诊断与校准报告、全部采集记录、训练集和更新模型，由 `output/results.json` 索引。
