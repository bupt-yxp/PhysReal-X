# 06 · 评测与反馈

评测模块五的策略，归档部署 Episode，诊断并回流失败样本，通过同条件专家恢复验证策略因素，重新训练后执行独立对照。

真机 Episode 必须同时提供 `source=real` 和不可变部署报告；仿真数据不会被标记为真机证据。物理参数辨识复用 `bounded_inverse_dynamics`，并要求两组独立真实采集。

在 PhysReal-X Conda 环境中运行 [demo.ipynb](demo.ipynb)。策略更新从原 ACT 检查点续训，并保持原预测时域。策略门控同时检查成功率、目标误差、轨迹误差和接触稳定性。输出包括评测面板、失败/恢复/更新策略同步动画、失败与因果报告、校准计划、门控结果、恢复数据和更新模型，由 `output/results.json` 索引。
