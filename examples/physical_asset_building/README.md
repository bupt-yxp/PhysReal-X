# 02 · 物理资产构建

在 PhysReal-X Conda 环境运行 [demo.ipynb](demo.ipynb)。模块二直接读取模块一重建的真实部件 Mesh、原始 start/end 关节范围和已标定视频，不要求预先生成无碰撞几何。

流程为：VLM 物性估计 → 视频标定 → 各部件受限 Delaunay 局部重网格 → 两帧以上 RGB-D 部件观测支持的交叉区源边细分 → 多帧观测状态拟合与受证据约束的重新三角化 → 从原始 Mesh 开始的 RGB、Mask、深度与运动约束联合分离 → 独立全范围间隙和留出帧验收 → 新碰撞代理与动力学测试。局部细分不填补未观测区域；整片重连不成立时仅在实际交叉邻域重试，危险的局部重连会逐块撤回，任何新三角连接均须通过源面和各拟合状态的拓扑、自交及双向覆盖检查。解缠时视频梯度参与两侧表面及关节轴／原点更新，交叉面进入局部松弛的可行性投影；只有通过无松弛的正间隙和独立检查才能发布。

模块一原始制品与 start/end 范围不变。拟合帧参与优化，检查帧只用于验收。默认要求完整运动范围至少 0.2 mm 正间隙；任一几何、视频或间隙门控失败时只保存诊断候选，不发布资产或重建碰撞代理。

视频标定入口是 `python examples/physical_asset_building/calibrate_video.py`：COLMAP 对齐视频相机及模块一 start/end，输出标定误差和范围外帧。数据估计的相机位姿不视为独立真值。受限 Delaunay 依赖 CGAL，安装要求见[安装说明](../../docs/getting-started/installation.md)。

Demo 展示源视频、原始和候选几何同步动画、局部接触、表面偏移、留出帧误差和全范围间隙。结果由 `output/results.json` 索引；USDZ 只在全部验收通过后导出。检查点可复用已有几何，但会重新绑定观测和接触，不能沿用旧算法的优化器状态。

算法边界与验收标准见[模块说明](../../docs/user-guide/physical-assets.md)。
