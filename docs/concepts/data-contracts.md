# 数据契约

平台中的规格和清单均为冻结模型。资源一旦以某个版本发布，其内容就不能原地修改。

## 资源关系

| 资源 | 主要内容 | 直接上游 |
| --- | --- | --- |
| `AssetSpec` | 链接、几何、关节和物理参数 | 外部几何制品 |
| `TaskSpec` | 条件、观测、动作与终止语义 | 资产 |
| `RunSpec` | 后端、策略、版本、配置与种子 | 资产、任务 |
| `Episode` | 带时间戳的观测、动作、奖励和事件 | 运行 |
| `DatasetManifest` | 已校验 Episode 摘要与信号模式 | Episode |
| `ModelManifest` | 权重、训练配置、数据血缘和指标 | 数据集 |
| `EvaluationReport` | 成功率、指标和失败案例 | 模型、评测数据集 |

## Episode 时间语义

每个普通步骤包含当前观测，以及基于当前观测执行的动作。末尾步骤只保存最终观测，不再包含动作与奖励：

```text
步骤 0：观测₀ + 动作₀ + 奖励₀
步骤 1：观测₁ + 动作₁ + 奖励₁
...
末尾步骤：观测ₙ
```

控制时间戳必须单调递增。每个传感器值还可以携带自己的采样时间，以表达异步多模态数据。

## 信号语义

`SignalSpec` 明确描述：

- 信号名称；
- 数据类型与形状；
- 物理单位；
- 逻辑坐标系；
- 采样频率。

`DataValue` 必须与对应规格完全一致。小型数值数据可以通过 `inline` 内联；图像、点云或权重等大对象通过 `ArtifactRef` 引用。

## 内容寻址

平台使用规范化 JSON 字节计算 SHA-256。相同内容得到相同摘要，所有下游资源保存上游引用的资源标识、版本和摘要。

```text
资源标识 + 语义版本 + SHA-256 摘要
```

因此，即使资源名称与版本相同，平台也能拒绝内容不一致的引用。

## 原子发布

制品先写入临时文件，完成同步和摘要校验后再原子重命名。元数据状态变化由 SQLite 事务保护。

数据集只有在全部 Episode 发布并通过校验后才会出现；训练器返回的权重也必须已存在且摘要正确，模型清单才允许注册。

## 失败语义

平台将预期运行错误转换为稳定错误码，命令行默认不输出回溯。评测失败按感知、规划、控制、接触、超时、数据质量或未知类别归档，为后续定向数据生成保留结构化依据。
