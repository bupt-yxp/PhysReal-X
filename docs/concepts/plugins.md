# 插件与适配器

PhysReal-X 通过窄接口接入外部能力。核心包导入时不会初始化 Torch、CUDA、仿真器、网络或工作区。

## 三类计算插件

### 仿真后端

仿真后端负责报告能力并创建会话。会话实现重置、步进和关闭生命周期，输出标准观测帧。

当前内置 `reference_drawer`，用于验证关节物体、确定性重置和任务条件，不代表生产物理精度。

### 策略

策略接收观测帧与任务规格并返回动作。内置策略包括：

- `scripted_drawer`：参考抽屉任务的规则策略；
- `torch_bc`：从已注册模型清单加载 Safetensors 权重并执行推理。

### 训练器

训练器接收训练规格、数据集清单、Episode 迭代器和制品写入端口。当前 `torch_bc` 训练器用于证明数据集到模型的完整血缘。

## 插件发现

第三方 Python 包通过 `physrealx.plugins` 入口点组注册能力。可以使用以下命令查看当前工作区可用插件及其版本：

```bash
physrealx plugins --workspace .physrealx
```

应用层按名称解析插件，并校验公共接口版本、插件版本以及模型推理策略是否可用。

## 生命周期要求

仿真适配器至少需要满足：

```text
创建会话 → 重置种子 → 观测 → 策略动作 → 步进 → ... → 关闭
```

同一次运行复用会话和策略，每条 Episode 只执行重置。关闭与错误清理必须幂等，取消或异常时不能发布部分数据集。

## 接入前检查

新适配器应先实现以下验证：

- 能力报告与不支持信号的快速失败；
- 固定种子的确定性测试；
- 信号类型、形状、单位、坐标系和时间戳测试；
- 生命周期与重复清理测试；
- 输入输出制品摘要测试；
- 异常和取消后的失败隔离测试；
- 真实运行时中的独立集成测试。

只有通过这些门槛后，文档才会把适配器列为正式支持。
