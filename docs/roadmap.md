# 能力边界与路线图

## 当前正式支持

- 严格的资产、任务、信号、运行、Episode、数据集、模型和评测契约；
- 本地 SHA-256 内容寻址制品库；
- SQLite/WAL 资源仓库与运行状态机；
- 抽屉关节物体参考后端；
- 规则抽屉策略；
- PyTorch 行为克隆训练与 Safetensors 权重；
- CPU 和 CUDA 12.1 推理评测；
- 命令行与带类型 Python 接口；
- 插件发现与失败隔离。

## 当前不代表正式支持

- Isaac Sim、Isaac Lab、Genesis 或 MuJoCo 生产适配器；
- RGB、深度、点云、力觉和接触的大规模数据管线；
- 视觉重建、三维高斯、部件分解和物理参数估计；
- ROS 2 真实机器人采集与部署；
- 分布式任务队列、远程工作节点和多用户权限；
- 大规模分片训练、断点恢复和多机多卡训练。

仓库不会以空壳模块表示这些能力已经完成。

## 优先接入顺序

1. 实现 Isaac Sim 或 Isaac Lab 隔离工作节点；
2. 生成 RGB、深度、关节与接触的标准 Episode；
3. 为多模态数据增加流式训练适配器；
4. 接入可扩展模仿学习与强化学习；
5. 接入视觉—语言—动作模型；
6. 接入 ROS 2 真实采集和部署；
7. 根据真实失败执行定向数据再生成。

## 服务化触发条件

只有出现多用户、多机器、排队、长任务恢复或共享对象存储需求时，才引入远程接口、任务队列、PostgreSQL 与兼容 S3 的存储。

在此之前，本地实现用于验证契约、数据语义和失败原子性，避免过早增加分布式系统复杂度。
