# 功能验收与证据范围

本页只记录当前源码与仍可复核的证据。旧对象与旧方法回执保存在 `.physrealx/example-history/`，不再作为当前 oven4 Notebook 的通过证明。

## 当前入口

`examples/real_assets_and_digital_twin/demo.ipynb` 使用 oven4 的 300 / 292 帧首末 RGB-D-Mask 状态与配套逆向建模 USD。参考模型含箱体、烤箱门和一个旋转关节。当前流程为：

```text
RGB/Depth/Mask 观测导入 → 相机恢复 → USD 条件米制对齐 → 深度增强
→ 训练帧深度到 USD 表面配准 → ArtGS 重建 → 配准绑定
→ 固定 DTArt 指标 → 对比动画与导出
```

Notebook 使用全部已注册 RGB-D-Mask 视图；重建固定选择每状态 100 张训练图和 50 张验证图。帧选择、Mask 校验与绑定、几何计算、质量门及导出都由项目 API 完成，Notebook 只声明输入、方法和业务参数。

ArtGS 2.5.0 使用每状态 100 张训练图和 50 张验证图，输出静态根与一个旋转部件。验证 PSNR 27.138 dB、前景 PSNR 25.242 dB、SSIM 0.9381、LPIPS 0.0597、轮廓 IoU 0.9520。训练前参考配准的最大验证中位距离为 4.31 mm、P90 为 8.19 mm；拟合状态为 start 90.00°、end 17.48°，start 状态触及 USD 上限并以 `joint_limit_saturated=1` 保留。

物理资产由两条 link、一个旋转关节、CoACD 碰撞体和显式物性先验组成，USDZ 自包含回读通过。MuJoCo 实际生成 20/20 条成功专家轨迹和 6 条失败轨迹。DINO-WM 的独立测试误差均优于保持基线：归一化状态 RMSE 0.4896 对 1.9091、潜在 MSE 0.2093 对 0.2347、RGB MSE 0.001247 对 0.002140；五秒正常 rollout 的推杆位置 RMSE 为 0.00788 m（基线 0.09260 m），门角 RMSE 为 0.06464 rad（基线 0.32325 rad）。零动作反事实中，任务相关门角 RMSE 为 0.05316 rad（基线 0.11800 rad）；静止推杆的误差不优于其近零保持基线，报告明确保留该结果。

反馈模块从 5 条失败轨迹生成同初态恢复示范并实际再训练 ACT；相同 5 个新种子的成功率由 0.4 提升至 1.0。

## 证据边界

- 逆向建模 USD 提供尺度、几何、关节与材质参考，不是独立物性实测。
- 数据集 Mask 属于版本化输入；USD 不参与生成目标轮廓。
- `status=COMPLETED/PASSED` 表示软件操作和声明的质量门完成，不表示论文指标达标。
- 当前没有真机设备、独立质量/受力记录或现场控制日志；真机闭环不属于本轮离线验收。
- `assets.evaluate_reconstruction` 对所有重建方法固定使用 DTArt 的 Axis Ang、Axis Pos、Part Motion 与平方 CD 定义；指标不属于 DTArt 重建方法的专属输出。

完整验收要求源码摘要、输入制品、方法描述符、权重摘要、输出制品和 Notebook 回执相互一致。修改 Notebook 或方法实现后，旧回执自动降为历史证据。
