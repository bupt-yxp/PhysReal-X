# 02 · 物理资产构建

**输入：** 模块一的真实重建部件、关节与配准，以及 laptop1 实拍视频。

**流程：** VLM 物性先验 → 视频证据检查 → 碰撞与装配 → 碰撞代理自动优化 → 仿真检查 → USDZ。

## 构建过程

1. `register_reconstruction_geometry` 仅将模块一原始重建转换到已注册的 link 坐标，逐点核验回投误差，并检查顶点数、三角面和颜色一致。保留重建缺口，禁止参考资产补面或移动部件。
2. `predict_physics` 使用固定版本的 VLM（当前 Qwen3-VL）预测部件质量、摩擦、恢复系数与关节阻尼等候选范围。惯量与重心按显式几何假设计算，仍标记为先验。
3. `build_collision(method="coacd")` 构建逐部件碰撞代理，`assemble` 组合几何、关节与物性。
4. `check_physics_feasibility` 默认用 361 个姿态扫描锁定的 start/end 范围并检查数值稳定性。局部伪碰撞可由 `refine_articulated_collision` 在视觉网格与关节范围不变的前提下修正碰撞代理，按源三角面自适应细分、重新拟合，再联合验收局部表面覆盖与穿插。优化目标比 1 mm 发布门槛额外保留 0.05 mm 余量，以降低离散姿态漏掉相邻峰值的风险；报告同时公开 0.0001 mm 的数值比较容差。

碰撞代理修正是基于碰撞一致性的**候选假设**；不单凭穿插证明真实表面错误。关节轴、start/end 范围和父子碰撞保持不变。原表面三角面归属必须全部保留；取消整块删除优化及删除比例配置。代理表面不足时细分对应源面片。初始薄层仅用于生成有体积的碰撞代理，不代表测得的真实厚度；后续局部裁切必须保留配置声明的最小原始厚度比例和体积比例。

局部验收默认使用 10 mm 空间单元：每个单元与接触区域在 2 mm 距离内的采样覆盖率至少 99%，双向最大采样误差不超过 3 mm。固定检测点包含全部源顶点、面心及独立表面采样，接触区域由初始碰撞证据确定。全局 P95/P99 只作诊断，不能替代局部门控。即使初始碰撞扫描通过，也执行覆盖检查。

细分到源三角面后仍有冲突时，先把失败源面聚类为连续接触片区，再把全关节扫描中每个失败姿态转换为局部支撑方向的分离不等式。序列凸子问题联合分配两侧支撑面的最小内缩量，并在信赖域内与原凸体做半空间求交；不会移动整块代理、视觉部件或关节。每轮硬性检查 2 mm 覆盖、3 mm 双向误差、公共边到相邻代理并集的连续性、厚度、体积、凸性和 GLB 往返结果，然后重建凸体并执行完整 MuJoCo 扫描。仅接受能降低真实穿插的最小合法步长，再基于新接触重线性化；不能删除整个凸体或发布失败候选。

细分有轮次和凸体数量上限。预算用尽或几何与运动约束冲突时返回 FAILED 和诊断，不发布为可用资产；组装时重新核验真实碰撞网格的覆盖，拒绝复用旧删除策略的验收记录。动画中橙色和紫色只表示 body/cover 代理归属；红点与逐帧毫米数值来自 MuJoCo 最深接触，才表示实际穿插。第三栏显示源表面到碰撞代理的误差，大于 3 mm 的偏差以饱和红色标注。

## 视频约束

`preview_physics_video` 同步展示 RGB、深度、整物体 Mask 与部件 Mask。

Demo 展示视频观测以便检查，视觉几何始终来自模块一，不自动调用表面拟合。若重建缺失表面，需要回到模块一依据采集证据改进重建；模块二不能以仿真可行为由补造几何。

手部施力未知时，动力学参数保持 VLM 先验。有已知作用量和独立采集后，可用 `calibrate_physics(method="bounded_inverse_dynamics")` 辨识惯量、阻尼和摩擦。

## 输出

| 产物 | 内容 |
| --- | --- |
| 物性先验与证据报告 | 候选范围、模型版本、视频就绪状态 |
| 资产与 USDZ | 真实视觉几何、碰撞代理、关节、物性和来源 |
| 几何证据 | 源部件 artifact、位姿回投误差、顶点/三角面/颜色保持核验及碰撞代理局部修正 |
| 可行性报告 | 全范围穿插、数值检查与修正前后对比 |
| 动画 | 视频观测；原始视觉、碰撞代理与局部拟合误差同步运动 |

可行性 `PASSED` 仅表示声明的仿真检查通过。独立物理验收需另提供测量轨迹，不能由先验或自身仿真结果替代。
