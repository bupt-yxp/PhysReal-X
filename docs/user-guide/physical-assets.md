# 02 · 物理资产构建

**输入：** 模块一的真实部件重建、关节及 start/end 配准，实拍 RGB-D 视频和已审核的部件 Mask。

**流程：** VLM 物性估计 → 视频标定 → 观测驱动表面拟合 → 表面与关节联合分离 → 新碰撞代理 → 独立全范围及动力学验收。

## 输入和不可变约束

模块一原始制品保持不可变。`register_reconstruction_geometry` 转换坐标并核验原顶点、三角面和颜色；模块二调整写为新候选。父子关系、逐帧关节位置及 start/end 范围固定，不能缩小范围规避碰撞。

`predict_physics` 使用 VLM（示例为 Qwen3-VL）初始化质量、摩擦、恢复系数、关节阻尼等范围，记录模型及输入来源。仿真可行不等于真实物性已辨识。

视频标定入口为 `examples/physical_asset_building/calibrate_video.py`：使用 COLMAP 重建视频相机，以机身 RGB-D/SIFT 对应对齐模块一 start/end。输出记录重投影误差、深度误差及范围外帧；它是数据估计，不是独立测量真值。

`assets.refine_video_articulation(evidence, config=...)` 接收 RGB、深度、整数部件 Mask、针孔内参、相机位姿和关节位置。start/end 原始训练观测也接入，可使用整体前景 Mask；不从候选几何制造监督标签。拟合帧与检查帧互斥，各帧可明确深度尺度。检查帧不进入梯度、对应绑定或候选选择。

当前联合求解入口处理两个部件、一个转动关节；其他运动结构会明确报错。下文的全部部件对检查针对该输入契约，不表示已经支持任意多关节装配。

RGB、深度和部件轮廓在完整铰接场景中共同渲染，再按部件归属提取可见像素；软轮廓也服从场景的硬遮挡。屏幕后方的机身不能穿过屏幕参与可见像素比较。完全遮挡或无有效深度的检查项仍明确记录不可测，不以零误差替代。

## 表面重建与联合分离

1. **部件重网格。** 对各部件执行三维受限 Delaunay，按共享边划分局部替换区域；仅接受源边界、拓扑和双向表面覆盖均合格的替换，失败区域保留源面并记录。铰链交叉区只细分至少由两帧拟合 RGB-D 部件观测支持的源边，两侧邻面同步细分；新增顶点位于原边上，视频检查帧不参与选边。不能跨空隙造面、丢面或把不同折叠层焊在一起。
2. **观测拟合与连接更新。** 可用拟合状态分别进行鲁棒 RGB-D 表面拟合，从可见像素更新状态表面的颜色。整体 Mask 仅对归属明确的点分配部件，无观测背面不吸附到前景。将拟合状态运回同一部件参考系后，由它们提出第二次局部重三角化；先用 1 mm 源面预算检查整片和交叉邻域，失败后以已配置的重网格边尺度（示例 3 mm）先复核**同一窄交叉区域**，再尝试扩大局部区域。成组重连若造成自交，则按原始边界划分的局部腔体逐块验收，保留安全重连并撤回危险腔体；未能确认的区域保留源面。原始表面和每个拟合状态均须保持拓扑、自交安全与双向覆盖，否则保留原连接并报告拒绝证据。较宽预算不会放宽留出视频及最终间隙验收，也不等同于任意错误连接的完整拓扑重建。
3. **观测驱动展开。** 对已交叉的输入，将独立拟合状态反向运输到同一个部件参考系，融合为共享初始表面；必须通过拟合误差、观测区间和自碰撞检查。形变正则围绕观测重建表面，而非持续把部件拉回原来交叉的形状。原始资产和 start/end 范围仍不修改。
4. **联合解缠。** 两侧表面、关节轴和原点共同优化 RGB-D、双向运动、面积积分的 Gaussian 形状排斥，以及三角面 Minkowski 间隙惩罚。所有发现的交叉对均保留；大三角面按重心坐标细分积分，积分点不是新增几何。共面重叠选择单一分离分支，避免相反梯度抵消。恢复阶段从原始 Mesh 出发，对全部拟合帧 RGB、部件 Mask、米制深度及共享运动求梯度；交叉接触进入带局部松弛的可行性问题，先压低最大间隙缺口，已达到物理间隙的接触不准退化。局部面积和自碰撞限制反馈到下一次求解；每步重新核查非线性间隙与视频误差。只有真正达到无松弛的 0.2 mm 间隙后，才继续受硬间隙约束拟合；最终由独立全范围验收决定是否通过。
5. **局部有效性。** 三角面面积、自碰撞及观测区间同时保护几何。IPC 收集完整更新路径上的候选特征，分离平面逐段证明线性顶点运动安全；无法证明的节点按已确认安全的前缀回退，再复核完整更新。阻塞特征不等同于实际碰撞。受阻节点的信赖域反馈到联合求解，避免一个危险点冻结整个部件。每步最多三次局部重求解，最后复核实际非线性间隙。

`minimum_clearance_m=0.0002` 是物理底线；`contact_reserve_m=0.0005` 只是软优化余量，可以消耗，不能将 0.7 mm 误作验收底线。表面、轴及原点的调整上限默认分别为 10 mm、8°、10 mm，并保留观测区间约束；这些信赖域不替代独立观测验收。

恢复阶段的视频梯度直接作用于两部件表面和关节。每组参数将反向抵消分离的观测分量投影掉，保留能够改善视频拟合的切向分量；非线性试步还检查全部拟合帧的观测损失，超过由深度误差预算导出的局部容差便回退。交叉区沿非线性排斥目标展开，并把较深、覆盖不同面片的交叉接触和全部已安全近接触送入联合投影。每次内层更新重新查询完整姿态接触集，避免沿用旧接触面而漏掉新交叉；不可行候选先按最大间隙缺口、再按相交面数排序，避免细分改变三角面数量时丢弃实际进展。最终验收仍使用独立导出网格和完整关节范围。相交三角面对数量不是穿插深度；Minkowski 支撑面偏移同样不能当作穿插深度。

求解器状态不替代约束复核。HiGHS 数值状态异常时对同一问题重试；次级优化失败只能回退到已核验的主目标解。分离目标得到可行解后，额外的最小位移目标最多再使用 10 秒，避免反复耗尽整次 120 秒预算；未完成该次级目标不会放宽约束。线性残差容差为 1 nm，实际观测约束残差容差为 2 nm；这是数值要求，不是传感器精度声明。

恢复阶段的二次投影使用 Clarabel，将对角 RMS 权重白化后求解稀疏问题，并消除已固定为零的松弛变量；HiGHS 保留在线性可行性／拟合投影中。QP 最多求解 10 秒，返回状态、原始毫米单位残差及耗时。超时的有限迭代只可作为候选步长，必须再通过部件内形变连续碰撞、三角面积、观测区间、视频误差及已分离接触的非线性检查；任一检查失败就回退。全运动范围的全部跨部件三角面对另行独立验收。不会因求解器报告成功而跳过几何复核。

## 独立验收与发布

验收读取实际导出的浮点网格，要求以下各项全部通过。

| 检查 | 标准 |
| --- | --- |
| 几何有效性 | 无部件自交、非流形边/顶点扇、重复面或退化面；原运动范围不变 |
| 观测一致性 | 视频部件及 start/end 点到面 P90 退化 ≤0.25 mm；逐检查帧 RGB MAE、Mask IoU 退化分别 ≤0.01，深度 P90 退化 ≤0.25 mm；缺失、无重叠或非有限测量失败 |
| 视觉表面间隙 | 全部部件对无三角面相交及闭合体包含，完整运动区间的保守间隙下界 ≥0.2 mm |
| 碰撞代理 | 重建代理，验证来源、局部误差及接触覆盖；保留每个源面，代理连续间隙同样 ≥0.2 mm |
| 动力学 | MuJoCo 全跨部件碰撞对、361 个基础姿态及危险姿态加密；三个起始姿态的 rollout 数值稳定且实际接触间隙达标 |

连续验收以 361 个关节位置划分完整范围，结合三角面包围球、距离 Lipschitz 界及铰链运动位移界进行空间和时间细分。离散姿态不能代表区间内安全。预算耗尽返回不确定并拒绝发布；负下界不等于测得的穿插深度。距离计算有明确数值余量，不声称精确算术证明。

表面通过后，`assets.rebuild_video_collision` 按已证实间隙分配代理误差预算，自动细分并拟合凸壳；超出误差或数量预算则失败。`assets.validate_video_articulation` 核验覆盖、连续间隙及动力学，包含软关节限位外的实际运动。USDZ 和资产注册必须等待全部检查通过。

失败结果的 `geometries` 为 `null`，代理及动力学标为 `BLOCKED`；`diagnostic_geometries` 只供诊断。发布契约复核具体测量，不仅依赖 `PASSED` 标签。`FAILED` 表示本候选不合格，不能据此证明原问题无解。

## 运行、检查点和方法边界

Demo 每批默认最多 120 次更新；可行阶段连续三轮活动集不变且等效运动步长小于 0.1 µm 时提前进入独立验收。恢复阶段不会在惩罚尚需递增时被该停滞规则提前终止。每五次更新保存参数、网格、接触方向、活动姿态、局部信赖域、Adam 和最优候选。

- `resume_checkpoint`：相同输入、关键配置、拓扑及实现的精确续跑，可增大迭代预算。
- `initialize_from_checkpoint`：实现更新后仅导入核验过的几何和关节参数，重建接触方向；不复用旧动量、排名或验收结论，与精确续跑互斥。
- `cached_result`：仅复用输入、配置和实现一致的完整结果，保留来源，禁止混用旧报告。

最近表面查询通过 Warp 分配到多 GPU；Gaussian 与 Minkowski 目标按姿态分配到 GPU 工作线程，梯度汇总回同一份表面及关节参数。CPU 使用整个求解周期内常驻的 `spawn` 进程池扫描姿态接触，避免继承 CUDA 上下文；子进程 BLAS 限为单线程，退出或异常时释放工作池。Gaussian 在 GPU 空间哈希中直接累计双向解析梯度，不在 CPU 构造完整邻接点对表；距离和积分使用 float64，哈希查询加入 float32 坐标误差余量，CPU 回退采用相同公式分块计算。IPC 保护部件自碰撞；恢复阶段采用 Clarabel 二次投影，可行性／拟合阶段采用 HiGHS 线性投影。`require_accelerator=True` 时 GPU 不可用会报错。报告记录设备、进程数和准备／总耗时；启用并行不等于已经测得固定加速倍数。

FV/EE/EV/VV 候选由同一个进程池分批检查，不丢弃候选或缩短待检查的更新区间。固定分离方向上的投影间隙是时间的凹函数，两端间隙的线性下界可以证明整段安全；加入浮点误差余量后，最多推进 32 次，未确认部分按阻塞处理。这避免原 IPC Tight Inclusion 在极小接触时刻进入无限制重试。最终完整更新仍须复核，导出表面另外执行 IPC 静态相交检查；关节旋转的完整区间继续使用独立扫掠验收，不能用线性顶点轨迹替代旋转。CPU Torch 限制线程预算并在退出时恢复，已可行阶段不再构建无用的 Gaussian 邻域。Notebook 可直接调用服务；普通 Python 脚本须将启动代码置于 `if __name__ == "__main__":` 下。

受限 Delaunay 工作进程依赖 C++17、CGAL/GMP/MPFR（Ubuntu：`build-essential libcgal-dev libgmp-dev libmpfr-dev`），首次编译后按源码指纹缓存。详见[安装说明](../getting-started/installation.md)。

实现参考 [ArtMesh §3](https://arxiv.org/html/2605.16582#S3) 的部件受限 Delaunay 和双向运动约束，可对照 [MeshSplatting 的 rDel 依赖](https://github.com/SonSang/effrdel)。当前不是作者完整训练程序的复现：采用鲁棒 RGB-D 拟合和 PyTorch3D，未复现球谐辐射与不透明度训练，也不保证任意输入都能得到分离解。多姿态非穿插及连续验收是额外实现的约束。

解缠目标参考 [Mesh-Untangling 官方源码](https://github.com/Simulation-Intelligence/Mesh-Untangling)：采用面积加权 Gaussian 表面积分和三角面 Minkowski 支撑面公式，并扩展为视频约束下的共享铰接模型。本实现使用两个固定物理尺度、确定的惩罚递增和 PyTorch 求导，并非作者的自适应带宽 CUDA 正向／反向流程序。开放表面没有被冒充为闭合实体 SDF；这些能量也不构成无碰撞证明。错误部件归属或错误拓扑仍需可靠观测支持，不能靠排斥项自动证明其已修复。

旧串行“关节拟合 → 表面拟合 → 推开部件”入口已删除，当前契约为 `physrealx.video-articulation-refinement/2`。固定视觉资产的 `refine_articulated_collision` 仍用于单独代理修正，不替代本 Demo 的表面和关节联合求解。
