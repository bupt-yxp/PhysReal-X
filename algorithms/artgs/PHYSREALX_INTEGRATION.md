# PhysReal-X 集成边界

ArtGS 作为 `geometry.reconstruct:artgs` 内嵌方法运行。平台负责验证米制多状态 RGB-D 输入、冻结训练配置、调用三阶段训练、构建原生 CUDA 扩展、发布 Gaussian/权重/视觉 Mesh，并生成带输入摘要和质量门禁的重建报告。

源码随 PhysReal-X 主仓库维护；根项目的 `artgs` 可选依赖是唯一 Python 依赖入口。数据、预训练权重、训练输出和本机编译结果不属于源码快照。
方法执行前会核对 `SOURCE.toml` 的上游提交与源码树摘要，并拒绝从 site-packages 或工作区外部载入同名 CUDA 扩展。
平台只调用 `train_coarse.py`、`train_predict.py`、`train.py` 和 `render.py`；上游的数据下载、视频与可视化辅助脚本按原样保留供审计，不是平台可执行 API。

ArtGS 主体是 Apache-2.0，但必需的 Gaussian rasterizer 和 Simple-KNN 仅允许
非商业研究与评估，因此方法整体标记为
`LicenseRef-ArtGS-Research-Only`。详细边界见根目录
`THIRD_PARTY_NOTICES.md` 与各组件的原始许可文件。

ArtGS 的外观重建指标不能替代关节、碰撞或物性验证；它只完成数字孪生流程中的视觉几何阶段。

评估阶段仅保留当前视图及指标计算所需张量在 GPU；RGB／深度／掩码缓存在 CPU，TSDF 仍使用原始逐帧渲染结果。该内存调整不改变采样数量、训练参数或指标定义。

训练图像也由 CPU 保存，当前帧损失计算时传至 GPU；光栅化入口将相机矩阵移至高斯所在设备，避免自定义 CUDA 算子接收 CPU 指针。显式 `joint_types` 仅指定运动组类型，轴与运动幅度仍由训练估计。

粗分解阶段分别从 `point_cloud_start.ply` 与 `point_cloud_end.ply` 初始化两个状态；两份点云只由各自状态的训练 RGB-D 视图生成。合并的 `points3d.ply` 仅满足上游场景读取契约，不参与两状态的粗模型初始化。

自动关节类型预测与联合重建使用同一粗重建点云约束和米制深度权重，且只在前景掩码内存在有效实测深度的像素计算深度损失。预测结果同时记录优化得到的半程旋转角和 10° 分类阈值，便于审计旋转/平移判定。

对于一个静态组和一个运动组，默认从两状态粗运动点云估计刚体变换，再取其对称半程变换初始化关节参数；候选旋转不能优于质心对齐平移时保留平移初始化。薄片或近对称部件存在多个等价 PCA 方向时，在拟合误差带内选择最小旋转，避免轴符号翻转产生虚假的近 180° 运动。

平台可显式提供 `reference_joint`：训练准备层只用训练视图的掩膜米制深度拟合配套 USD 表面，并用验证视图执行门禁；原生训练进程只接收由该配准换算出的对称半程关节初值。参考几何不进入 RGB/深度损失，训练报告必须标记 `MODEL_CONDITIONED`，且保存初始化和完整配准证据。未提供时继续使用上述粗运动几何初始化。

联合重建在没有可恢复检查点时使用相同的两状态几何初始化，避免类型阶段判定为旋转后又从近单位关节重新开始并退化为小运动；恢复训练则优先加载已有权重。
